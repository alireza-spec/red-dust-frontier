# Original audio

These WAV files were generated specifically for Red Dust Frontier in 2026 and are released under the repository MIT license:

- `dust-wind-drone.wav` — low desert wind bed
- `frontier-call.wav` — distant harmonica-like motif
- `saddle-click.wav` — interaction cue

The browser build also synthesizes responsive UI cues with Web Audio so it remains lightweight and playable without a large audio bundle.
