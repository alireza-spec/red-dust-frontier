# Red Dust Frontier

An original cinematic western vertical slice built with Godot 4. This is not a reproduction of Red Dead Redemption and uses no Rockstar names, characters, story, music, or assets.

## Current vertical slice
- Procedurally assembled desert frontier scene
- Warm sunset lighting, fog, sky, terrain, mesas, and a small settlement
- Third-person movement with sprint and camera follow
- Rideable frontier horse interaction (`E`)
- Mission marker and objective HUD
- No external assets required for the first playable build

## Run
1. Install Godot 4.3+.
2. Import this repository as a project.
3. Press F6/F5 and use `WASD` or arrow keys. Hold `Shift`/`Space` to sprint. Press `E` near the horse.

## Direction
This repository is the foundation for a polished original western adventure. Art packs, animation, audio, quest content, save system, combat, and optimization should be added in isolated milestones rather than faking a full AAA game in one unfinished step.
