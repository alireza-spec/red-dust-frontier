# Red Dust Frontier

[![Play the web build](https://img.shields.io/badge/PLAY%20THE%20WEB%20BUILD-red--dust--frontier-b64731?style=for-the-badge)](https://alireza-spec.github.io/red-dust-frontier/)

An original cinematic western vertical slice set around Dusthaven. This is not a reproduction of Red Dead Redemption and uses no Rockstar names, characters, story, music, or assets.

## Play online

**[Launch Red Dust Frontier](https://alireza-spec.github.io/red-dust-frontier/)** — the browser build is an original Three.js/WebGL 3D western vertical slice with procedural scenery, responsive UI, generated audio cues, and no installation required.

## Web build

- `web/index.html` — playable presentation and HUD
- `web/styles.css` — responsive cinematic interface
- `web/game.js` — original Three.js/WebGL scene, movement, mission state, procedural environment, and Web Audio cues
- `web/assets/images/` — handcrafted SVG visual identity and branding
- `web/assets/audio/` — original WAV audio created for this project

Controls: Desktop uses `WASD` / arrow keys to move, `Shift` or `Space` to gallop, and `E` to interact near the horse. On phones and tablets, use the on-screen directional pad plus **GALLOP** and **INTERACT** buttons. Tap **Enter the Frontier** to start and enable audio.

## Godot build

The original Godot 4 project remains available as the desktop foundation:

1. Install Godot 4.3+.
2. Import this repository as a project.
3. Press F6/F5 and use `WASD` or arrow keys. Hold `Shift`/`Space` to sprint. Press `E` near the horse.

## Original asset policy

No images, music, or effects were scraped from Google or copied from protected games. Visuals are handcrafted SVG/canvas art, and audio is original generated material. Future commissioned or downloaded assets must be added with a license note and attribution in the relevant asset folder.

## Direction

This repository is the foundation for a polished original western adventure. Next isolated milestones are combat, animation, NPC schedules, expanded quests, save system, accessibility, and performance passes.
